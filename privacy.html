Privacy Policy

Application: Unraid Rclone Backup
Effective date: October 16, 2026

Unraid Rclone Backup is a personal, non-commercial integration operated by the owner of the connected Google account. It uses the open-source rclone tool to store, update, inspect, verify, and manage backups of an Unraid NAS on the owner's Google Drive.

Information accessed

When the owner grants Google OAuth access, rclone may access Google Drive file contents, file names, paths, identifiers, sizes, checksums, and other metadata required to manage backups. The requested authorization may permit creating, reading, updating, and deleting Drive files.

Purpose and use

Access is used solely for the operator's own backup, restore, consistency-check, and retention operations. Deletions occur only as directed by the operator's configured backup retention policy.

Storage and sharing

Google data remains within the operator's chosen backup storage and systems used to process those backups. Authentication tokens are stored in the operator's local rclone configuration. No independent application server receives Google Drive data, and the website does not receive OAuth tokens, file contents, or backup logs. Google user data is not sold, used for advertising, or shared with unrelated third parties.

Retention and deletion

Backup copies are retained according to the operator's configured schedules and retention rules. The operator can remove backup data in Google Drive at any time and can revoke OAuth access in their Google Account settings. Local credentials and logs can be deleted by the operator from their own systems.

Security

OAuth tokens and backup contents are not placed in the public repository for this website. Access to the backup systems is managed by the operator. This website is informational only and contains no sign-in flow, analytics integration, or forms.

Contact

For questions, contact the operator via their GitHub profile.

Changes

Changes to this policy will be published at this URL with an updated effective date.
