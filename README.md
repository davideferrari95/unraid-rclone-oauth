# Unraid Rclone Backup OAuth Information Site

Public static documentation for a personal Google Drive OAuth application used with rclone and an Unraid NAS.

## Pages

- [Homepage](https://davideferrari95.github.io/unraid-rclone-oauth/)
- [Privacy Policy](https://davideferrari95.github.io/unraid-rclone-oauth/privacy.html)

This public repository contains no OAuth credentials, backup files, private configuration, or server addresses.

## Publishing With GitHub Pages

Open **Settings → Pages**, select **Deploy from a branch**, choose **master** and **/(root)**, then save.

GitHub Pages must be enabled before the links above are live.
